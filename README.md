# Full Stack E-Commerce Website

A responsive full-stack e-commerce web application built using HTML, CSS, JavaScript, Node.js, and Express.js. The project includes user authentication, shopping cart functionality, product management, order processing, and backend API integration.

---

# Features

## User Features
- User Registration & Login
- Product Listing
- Product Details Page
- Shopping Cart
- Quantity Management
- Order Placement
- Order History
- Responsive Design

## Admin Features
- Add Products Dynamically
- Backend Product Management
- JSON-based Data Storage

---

# Tech Stack

## Frontend
- HTML5
- CSS3
- JavaScript

## Backend
- Node.js
- Express.js

## Storage
- JSON Files
